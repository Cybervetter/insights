# Contributing

Public repositories in this organisation are published for transparency and reference, not for external collaboration.

We do not accept external issues, pull requests, or comments on any public repository here. Any pull request opened from outside the organisation will be closed and locked automatically, without review. This is a policy decision, not a reflection on the contribution itself.

If you have a question about CYBERVETTER's work, use the contact details at [cybervetter.com](https://cybervetter.com).
